💰 KASFILLA — Kas Kelas IF-1D

Aplikasi web manajemen kas kelas sederhana untuk mencatat pemasukan, pengeluaran, iuran, anggota, dan laporan keuangan secara digital.

---

📖 Deskripsi

KASFILLA adalah aplikasi berbasis web (Single Page Application) yang dibuat untuk mempermudah pengelolaan kas kelas. Semua data disimpan di localStorage browser sehingga tidak memerlukan server atau database eksternal.

Aplikasi ini mencakup 6 modul utama:

| Modul | Fungsi |
|-------|--------|
| 🏠 Dashboard | Ringkasan saldo kas, total pemasukan, pengeluaran, dan daftar tunggakan |
| 👥 Anggota | Manajemen data anggota (tambah, edit, hapus) |
| 💵 Iuran | Daftar jenis iuran beserta nominal dan periode |
| 📥 Pembayaran | Catat riwayat pembayaran iuran anggota |
| 📤 Pengeluaran | Catat dan kelola pengeluaran kas |
| 📊 Laporan | Rekap per anggota (total dibayar & tunggakan) |

---

✨ Fitur

- ✅ Navigasi SPA tanpa reload (sidebar)
- ✅ CRUD Anggota, Iuran, Pembayaran, Pengeluaran
- ✅ Perhitungan otomatis saldo, pemasukan, pengeluaran, tunggakan
- ✅ Rekap laporan per anggota + filter
- ✅ Data persisten di `localStorage`
- ✅ Desain modern (glassmorphism + fluid animation)
